# SaludConCiencia · Configuración del Proyecto

Este proyecto es una plataforma interactiva de divulgación científica y acompañamiento humano para pacientes de Leucemia Mieloide Crónica (LMC), creada por Shirley Gaviria.

- **Diseño:** Tokens CSS en `src/styles/global.css` basados en la paleta `#131313`, `#FFFFFF`, `#579BFC`, `#D9EE53`, `#C8D1E1`.
- **Iconos:** 100% Lucide Icons monocromáticos y minimalistas.
- **CMS:** Sveltia CMS privado en `/admin/`.
